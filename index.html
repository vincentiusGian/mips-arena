Input conventions

            
Custom InputNumbers separated by spaces or newlines. All numbers are queued for syscall 5.

            
inputIf .data defines an input label, the numbers are also stored as words at that label.

            
$a0, $a1The number of values and the address of the input label are set automatically before the program starts.

            
Terminal modeToggle with the Terminal/Split button above the output panel. Input and output share one terminal.

            
Interactive inputsyscall 5 pauses and asks for a value; type it and press Enter instead of filling Custom Input first.

          


          

            
Registers

            
$zeroAlways 0; writes are ignored.

            
$atAssembler temporary.

            
$v0–$v1Result values; $v0 also holds the syscall number.

            
$a0–$a3Arguments. $a0/$a1 hold input information.

            
$t0–$t9Temporaries; free to use.

            
$s0–$s7Saved registers; free to use in this simulator.

            
$gp, $sp, $fpGlobal, stack, and frame pointers. $sp starts at 0x7fffe000.

            
$raReturn address for jal/jalr.

            
hi, loResults of mult/div; read with mfhi/mflo.

          


          

            
Arithmetic

            
add $rd,$rs,$rtSigned addition; overflow raises an error.

            
addu $rd,$rs,$rtAddition without overflow checking.

            
sub $rd,$rs,$rtSigned subtraction; overflow raises an error.

            
subu $rd,$rs,$rtSubtraction without overflow checking.

            
addi $rt,$rs,immAdd a 16-bit immediate; overflow is checked.

            
addiu $rt,$rs,immAdd an immediate without overflow checking.

            
mult $rs,$rt64-bit result stored in hi and lo.

            
multu $rs,$rtUnsigned multiplication.

            
div $rs,$rtSigned division: quotient in lo, remainder in hi.

            
divu $rs,$rtUnsigned division.

            
mfhi $rd / mflo $rdCopy hi or lo into a register.

            
lui $rt,immLoad the upper 16 bits of a register with an immediate.

            
neg / negu $rd,$rsSigned / unsigned negation.

          


          

            
Logic, shifts, and comparisons

            
and or xor nor $rd,$rs,$rt32-bit bitwise operations.

            
andi ori xori $rt,$rs,immBitwise operations with an immediate.

            
slt $rd,$rs,$rt1 if $rs < $rt (signed).

            
sltu $rd,$rs,$rtUnsigned comparison.

            
slti / sltiu $rt,$rs,immCompare with an immediate.

            
sll / srl / sra $rd,$rt,shLeft shift, logical right shift, arithmetic right shift.

            
sllv / srlv / sravShift by an amount from a register.

            
not $rd,$rsBitwise inversion.

            
seq / sne $rd,$rs,$rt1 if equal / not equal.

          


          

            
Memory

            
lw $rt,off($base)Load a 32-bit word; the address must be a multiple of 4.

            
sw $rt,off($base)Store a 32-bit word.

            
lb / lbu $rt,off($base)Load signed / unsigned byte.

            
sb $rt,off($base)Store the low byte.

            
lh / lhu / shLoad/store a 16-bit halfword.

            
la $rt,labelLoad a label address into a register.

            
li $rt,valueLoad a constant or label address.

            
move $rd,$rsCopy a register.

            
label($reg)Address = label address + register value, e.g. arr($t0).

          


          

            
Control flow

            
beq / bne $rs,$rt,labelBranch if equal / not equal.

            
blt / ble / bgt / bgeSigned branches: <, <=, >, >=.

            
blez / bgtz / bltz / bgezBranch based on the sign of $rs.

            
beqz / bnez $rs,labelBranch if zero / non-zero.

            
j labelUnconditional jump.

            
jal labelJump and save the return address in $ra.

            
jr $rs / jalr $rsJump to an address held in a register.

            
haltStop the simulation without changing registers.

            
nopNo operation.

          


          

            
Data directives

            
.data / .textStart the data / code segment.

            
.globl mainIgnored; execution starts at the main label.

            
.word / .half / .byteStore 32/16/8-bit values; multiple values are allowed.

            
.asciiz / .asciiStrings, with / without a null terminator.

            
.space n / .zero nReserve n zero bytes.

            
.align nAlign the data address to 2^n bytes.

          


          

            
Syscalls

            
$v0=1Print the integer in $a0.

            
$v0=4Print the string at address $a0.

            
$v0=5Read the next integer from Custom Input into $v0.

            
$v0=9Simple memory allocation.

            
$v0=10Exit the program.

            
$v0=11Print one character from $a0.

          


          

            
Shortcuts

            
F5Run or pause.

            
F10Execute one instruction.

            
Ctrl+EnterRun from the start.

            
TabIndent by four spaces.
